规格要点 · 自动暂停规则 
running ─失败─▶ failing(count+1)
failing ─成功─▶ running(count=0)
failing ─count≥3─▶ paused(自动·开关回弹)
paused ─仅手动启用─▶ recovering ─1s─▶ running
  • 阈值：连续失败 3 次
  • 暂停后不自动重试
  • 手动启用恢复，计数归零

规格说明 · 采集源连续失败自动暂停

采集任务每次失败将递增该源「连续失败」计数（1-2 次以告警色提示，第 3 次转错误色），成功一次即归零；连续失败达到阈值 3 次后，源自动转入「已自动暂停」：整行错误底色、状态徽标转错误态、开关 120ms 回弹至关闭位、行首出现警示图标，操作列提供「启用」入口。

  • 阈值：连续失败 3 次自动暂停，成功一次计数归零；
  • 暂停后不自动重试：调度器跳过该源，不消耗采集配额；
  • 手动启用恢复：点击「启用」或开关，约 1s 后回到运行中并清零计数。
