## 关键实现约定

1. 生成提示词要求只输出 JSON：{componentName: PascalCase, description: 一句话, code: React 函数组件完整源码}；代码必须用 @mt/ui tokens（import { tokens } from "@mt/ui"），禁止硬编码颜色
2. 桩模式固定组件：GreetingCard（使用 tokens.color.primary + antd Card），保证 CI/E2E 确定性；图片输入桩模式同样返回固定组件
3. 预览打包：esbuild.build({ stdin: code, bundle: true, format: "iife", jsx: "automatic", external 无 }) + HTML 壳（含 <div id="root"> + 脚本挂载）；esbuild 需加入 designer-server 依赖；产物内存 Map 缓存（previewId → html）
4. 生成失败也落 generations（status=failed + error），历史可回看
5. 组件沉淀重名：INSERT ON CONFLICT (name) DO NOTHING，返回幂等结果
