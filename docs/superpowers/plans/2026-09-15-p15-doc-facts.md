# P15 实施计划

## T1 事实解析与守卫（TDD）

1. 新增 `docs-facts.test.mjs`，先锁定 coverage 解析、接口扫描、生成漂移与历史 spec 标识；
2. 实现 `docs-facts.mjs`：
   - 解析 coverage 表格；
   - 扫描 React Route 与 Nest Controller；
   - 生成 feature-map、coverage-view、interface-index；
   - 校验生成物与源码一致；
3. 挂接 `pnpm docs:facts` 与 `test:infra`。
4. PR CI 按 base...head 变更文件执行文档影响检查：接口/路由变更需接口证据，功能/数据契约/公共包行为变更需功能映射或模块文档证据。

## T2 文档结构拆分

1. 按现有章节拆 `docs/code-wiki/`：overview、packages、gateway、八个应用、communication、frontend、backend、llm、engineering、dependencies、decisions；
2. `docs/CODE_WIKI.md` 改为模块索引和维护规则；
3. specs 增加 README 索引，历史设计加统一标识；
4. state 当前化，历史内容移入 `docs/memory/history.md`。

## T03 验证与交付

1. 重复运行 docs:facts，确认幂等；
2. 目标测试、docs lint、infra、完整 qa、smoke；
3. 独立审查文档内容与守卫有效性；
4. 更新 coverage、CHANGELOG、state、changeset，创建 PR 并等待 CI 三段全绿。
